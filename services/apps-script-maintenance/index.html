COMMON SYMPTOMS

常見的 Apps Script 問題

表單沒有寫入

畫面顯示完成，但 Sheet 沒有新增資料或狀態停在處理中。

欄位或權限變更

表頭、檔案擁有者、OAuth 或共用權限變更後，原流程中斷。

觸發器與部署

排程未執行、Web App 版本不一致，或正式與測試環境混用。

SAFE RECOVERY

修復前先保留可回復證據

不直接重建 Sheet，也不以重新部署掩蓋真正原因。

  • 確認 Script、Deployment 與 Spreadsheet 身分
  • 備份來源與欄位結構
  • 分離 Production 與 TEST
  • 重現錯誤並保留紀錄
  • 最小修改與回歸測試
  • 核准後才執行正式變更

維護流程

  1. 唯讀盤點
  2. 建立測試重現
  3. 修正與回歸
  4. 人工核准發布
